# 🐹 햄찌의 가상국가 카톡 운영 프로젝트

햄찌TV용 가상국가 **햄찌국**의 시민·국가·경제 기능을 확장하기 위한 Node.js 서버 프로젝트입니다.

## 현재 구현
- 🐹 시민 가입/정보
- 💰 개인 잔액
- 🏛️ 국가 정보
- 🧾 세금
- 📰 뉴스
- 📖 도움말
- 🔌 `POST /api/bot/message` 봇 어댑터

## 실행

```bash
cd hamjji-country
npm install
copy .env.example .env
npm start
```

Linux/macOS에서는 `cp .env.example .env`를 사용하세요.

## API

요청:
```json
{
  "kakao_id": "123",
  "nickname": "햄찌",
  "message": ">내정보"
}
```

응답:
```json
{
  "ok": true,
  "text": "[ 🐹 시민 정보 ] ..."
}
```

## 카카오 연결 주의

이 프로젝트는 **카카오 오픈채팅의 일반 메시지를 비공식적으로 가로채는 기능을 포함하지 않습니다.** 실제 카카오 연결은 카카오가 허용하는 공식 API/봇 연동 방식 또는 사용 가능한 공식 어댑터를 통해 붙여야 합니다.

다음 단계에서 경제, 주식, 부동산, 공장, 선거, 직급, 외교, 관리자 페이지를 모듈로 추가할 수 있습니다.
