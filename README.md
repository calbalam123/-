# 💰 마르스 경제봇

이 저장소에 마르스 경제봇 서버와 경제 엔진을 넣었습니다.

## 실행
1. Node.js 20+ 설치
2. `npm install`
3. `.env.example`을 `.env`로 복사
4. 카카오 Developers에서 Kakao Login 활성화
5. Redirect URI: `http://localhost:4000/oauth/kakao/callback`
6. `npm start`
7. `http://localhost:4000`

## 명령어
`>도움말`, `>계좌`, `>출석`, `>송금 @닉네임 금액`, `>시장`, `>주식매수 MARS 10`, `>주식매도 MARS 5`, `>보유주식`, `>상품시장`, `>상품구매 철강 10`, `>부동산목록`, `>부동산구매 1`, `>내부동산`, `>공장목록`, `>공장구매 1`, `>내공장`, `>생산 1`, `>채권목록`, `>채권구매 1 10000`, `>예금 50000`, `>출금 10000`, `>인구`, `>국가`, `>세계`, `>또박`, `>신고 @닉네임 사유`, `>보장`, `>시스템`

## 외부 봇 어댑터
`POST /api/bot/message`에 `{ "kakao_id":"123", "nickname":"홍길동", "message":">계좌" }`를 보내면 경제 엔진이 응답을 JSON으로 돌려줍니다. `x-bot-secret` 헤더를 설정할 수 있습니다.

중요: 이 엔드포인트는 카카오 오픈채팅 메시지를 스스로 수신하는 공식 API가 아닙니다. 카카오 Developers의 로그인/메시지 API와 오픈채팅 일반 메시지 수신은 별도 영역이므로, 실제 오픈채팅 자동응답은 허용된 공식 연동 수단 또는 별도 봇 어댑터가 필요합니다.
