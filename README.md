# 🌲 파인봇 — 가상국가 통합 경제봇

기존 마르스 경제봇을 확장한 Node.js + SQLite 기반 가상국가 통합 경제봇입니다.

## 핵심 설계

- 여러 가상국가가 하나의 파인봇 인스턴스와 SQLite 데이터베이스를 공유합니다.
- 국가별 통화, 국민 계좌, 국고, 세율, 구성원 및 관리자 권한을 분리합니다.
- 국가별 카카오 오픈채팅방을 연결할 수 있습니다.
- 국가 간 경제 데이터는 섞이지 않도록 `country_id` 기준으로 구분합니다.
- 기존 마르스 경제봇의 `>` 명령어와 기능은 호환성을 위해 유지했습니다. 새 통합 국가 기능은 `.` 접두사를 사용합니다.

## 실행 환경

- Node.js 20 이상
- Windows 권장
- SQLite (better-sqlite3)

## 설치 및 실행

1. 저장소를 내려받습니다.
2. 프로젝트 폴더에서 `npm install`을 실행합니다.
3. `.env.example`을 복사해 `.env` 파일을 만듭니다.
4. `BOT_WEBHOOK_SECRET`을 충분히 길고 임의적인 값으로 변경합니다.
5. `npm start`를 실행합니다.
6. 브라우저에서 `http://localhost:4000`을 열어 테스트합니다.

Windows 데스크톱 앱은 `npm run desktop`, 설치 파일 빌드는 `npm run dist`를 사용합니다.

## 파인봇 통합 경제 명령어

| 명령어 | 설명 |
|---|---|
| `.도움말` | 통합 경제 명령어 |
| `.국가등록 국가명 통화명 통화코드` | 새 가상국가 생성 |
| `.국가목록` | 등록된 국가 목록 |
| `.국가가입 국가코드` | 국가 가입 및 활성 국가 선택 |
| `.국가정보` | 국가 정보, 국고, 세율, 구성원 |
| `.계좌` | 현재 국가의 개인 계좌 |
| `.출석` | 국가 통화로 출석 보상 |
| `.송금 @닉네임 금액` | 같은 국가 구성원에게 송금 |
| `.국고` | 국가 재정 확인 |
| `.세금설정 0~50` | 국가 관리자 세율 설정 |
| `.국고지급 @닉네임 금액` | 국고에서 국민에게 지급 |
| `.국가관리자 @닉네임` | 국가 설립자가 관리자 임명 |
| `.방연결 국가코드` | 현재 오픈채팅방과 국가 연결 |
| `.방해제` | 현재 오픈채팅방 연결 해제 |

### 첫 국가 만들기

1. 봇 어댑터가 전달하는 메시지로 `.국가등록 대한제국 원 KRW`를 실행합니다.
2. 응답으로 표시되는 국가 코드를 확인합니다.
3. `.방연결 국가코드`로 현재 채팅방을 연결합니다.
4. 다른 사용자는 `.국가가입 국가코드`로 가입합니다.
5. `.계좌`, `.출석`, `.송금`, `.국고`를 이용합니다.

국가를 만든 사용자는 해당 국가의 설립자(owner)가 됩니다. 설립자와 국가 관리자만 방 연결, 세율 변경, 국고 지급 등의 관리 명령을 실행할 수 있습니다.

## 봇 어댑터 연동

`POST /api/bot/message` 요청 예시:

```json
{
  "kakao_id": "123456789",
  "nickname": "홍길동",
  "room_id": "openchat-room-identifier",
  "message": ".계좌"
}
```

요청 헤더에 `x-bot-secret: .env에 설정한 비밀값`을 포함해야 합니다. 응답은 다음과 같습니다.

```json
{ "reply": "..." }
```

`room_id`는 국가별 채팅방을 구분하는 데 사용됩니다. 어댑터가 같은 방의 메시지마다 동일한 `room_id`를 보내야 합니다.

## 카카오 오픈채팅 연동에 관한 중요 안내

이 프로젝트의 웹훅은 메시지를 받아 경제 명령을 처리하는 서버 인터페이스입니다. 웹훅 자체가 카카오 오픈채팅 메시지를 직접 수신하거나 전송하지는 않습니다. 카카오 로그인 API와 일반 오픈채팅 메시지 수신은 별개이므로, 실제 자동응답에는 사용 환경에서 허용되는 공식 연동 수단 또는 별도 봇 어댑터가 필요합니다. 어댑터는 위 웹훅에 사용자 ID, 닉네임, 방 ID, 메시지를 전달하고 반환된 `reply`를 채팅방에 전송하도록 구성해야 합니다.

## 데이터베이스

SQLite 파일은 실행 작업 디렉터리의 `mars.sqlite`에 생성됩니다. 국가별 데이터는 `countries`, `country_members`, `country_wallets`, `country_rooms`, `country_transactions` 테이블에 저장됩니다.

## 개발 상태

현재 브랜치의 1차 목표는 국가 등록·가입·방 연결·국가별 지갑·송금·국고·세율·관리자 권한의 기반을 제공하는 것입니다. 주식, 기업, 무역, 외교, 군사 등 추가 모듈은 국가별 데이터 격리를 적용해 단계적으로 확장합니다.
